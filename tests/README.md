# Проверка обработки DOCX

`npm test` создаёт настоящие DOCX-пакеты в памяти и проверяет движок без браузера.
Исходники фикстур находятся в `fixtures.ts`; персональных учебных работ в тестах нет.

Основная фикстура содержит явное и наследуемое оформление, вложенные таблицы,
PNG с корректными контрольными суммами, гиперссылку, сноску, формулу Office Math,
нумерованный список, два раздела, колонтитулы и пользовательскую XML-часть.

Регрессии проверяют обнаружение нарушений, отдельные и общие исправления,
пользовательский профиль, повторную обработку и отсутствие изменений текста.
Все ZIP-части кроме основного XML должны остаться побайтово идентичными.
Защищённые фрагменты (таблицы, формулы, поля, правки рецензента) проверяются
дополнительно на уровне XML-поддеревьев.

Негативные сценарии включают повреждённый ZIP/XML, несоответствие CRC,
завышенные размеры, ложную запись конца ZIP внутри комментария, чрезмерную
вложенность XML, DTD, макросы и цифровые подписи. Тесты не выделяют память
под заявленные вредоносные размеры и не содержат исполняемых макросов.

После тестов доступны `/tmp/norma-validation/original.docx` и
`/tmp/norma-validation/fixed.docx`. Их можно дополнительно открыть в Word,
LibreOffice или `python-docx`. Это отдельная проверка совместимости: успешный
разбор собственного XML-парсером сам по себе не гарантирует точность отображения.
